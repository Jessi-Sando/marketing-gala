# Mi Primer Repositorio

Bienvenido! Este repositorio contiene utilidades simples en Python.

## Funciones disponibles

- `saludar(nombre)` — Devuelve un saludo personalizado
- `sumar(a, b)` — Devuelve la suma de dos numeros
- `es_par(n)` — Retorna True si el numero es par

## Uso

```python
from utils import saludar, sumar, es_par

print(saludar("Jessica"))   # Hola, Jessica!
print(sumar(3, 4))          # 7
print(es_par(6))            # True
```

## Instalacion

No requiere dependencias externas. Solo Python 3.8+.
